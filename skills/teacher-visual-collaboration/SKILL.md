# Teacher Visual Collaboration

Use this skill when a teacher attaches a screenshot.

- Inspect only the attached image and the current course context; do not assume hidden UI state.
- Identify the referenced region, visible problem, desired outcome, and affected course scope.
- Explain the proposed change briefly before any destructive or structural operation.
- For content-generation requests, route to the corresponding standard artifact workflow.
- For file moves, deletions, or structural changes, produce a confirmation plan first.
- If the screenshot is unreadable or the target is ambiguous, ask for one focused clarification.
