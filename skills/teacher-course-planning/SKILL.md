# Teacher Course Planning

Use this skill when a teacher asks for a teaching syllabus or teaching plan.

- Ground every decision in uploaded materials and the current course knowledge graph.
- Align course objectives, modules, lessons, activities, assessment evidence, and source citations.
- Respect the teacher's week or lesson count; never silently invent additional teaching hours.
- Start the platform's standard generation workflow and persist the result as a reviewable course artifact.
- Treat the teacher-approved version as authoritative; later regeneration creates a new review version.
