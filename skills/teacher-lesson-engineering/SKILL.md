# Teacher Lesson Engineering

Use this skill for lesson-level preparation and artifact generation.

- Resolve the requested module, week, or lesson before writing.
- Reuse course materials, knowledge graph nodes, existing approved artifacts, and page-level citations.
- Write measurable objectives, teachable knowledge-point bullets, timed activities, presentation pages, narration, exercises, and assessment criteria as separate structured files.
- Update an existing empty file instead of creating a duplicate. Preserve non-empty teacher content unless replacement is explicitly requested.
- Generation enters the standard generation—review—visualization workflow. Structural moves and deletions require confirmation.
- Prefer concise Markdown headings and bullets so files render as readable teaching cards.
